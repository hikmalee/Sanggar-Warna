# Sanggar Warna Creative Hub

Landing page awal untuk Sanggar Warna Creative Hub dengan konsep kids friendly, ilustrasi maskot fantasi, warna ceria, dan animasi ringan.

## Isi folder
- `index.html` — struktur halaman website.
- `style.css` — desain responsif, warna, layout, dan animasi.
- `script.js` — interaksi menu mobile, tombol kembali ke atas, dan navigasi aktif.

## Cara memasang ke GitHub
1. Ekstrak file ZIP ini.
2. Buka repository `https://github.com/hikmalee/Sanggar-Warna`.
3. Pilih **Add file → Upload files**.
4. Unggah `index.html`, `style.css`, dan `script.js` (serta README jika ingin mengganti README lama).
5. Klik **Commit changes**.
6. Buka **Settings → Pages**, pilih branch `main` dan folder `/ (root)`, lalu simpan.
7. Tunggu proses deployment GitHub Pages selesai.

Catatan: halaman ini adalah prototipe front-end. Fitur akun siswa, dashboard orang tua/mentor, database portofolio, pendaftaran kelas, dan data kompetisi/beasiswa belum terhubung ke backend.
